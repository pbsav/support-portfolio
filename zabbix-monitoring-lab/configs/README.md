# Примеры конфигурации

Это подготовленные для документации примеры по выполненной настройке, **не экспорт действующих файлов VM**. Паролей в них нет.

- [zabbix_server.conf.example](zabbix_server.conf.example) — только параметры подключения сервера к PostgreSQL; остальные параметры поставляемого файла сохраняются.
- [nginx-zabbix.conf.example](nginx-zabbix.conf.example) — фрагменты, проверенные в ходе практики. Файл нельзя использовать как полную замену nginx.conf.
- [web-scenario-and-trigger.yaml](web-scenario-and-trigger.yaml) — описание полей сценария и триггера для ручного повторения. Это не формат импорта Zabbix и не результат экспорта API.

IP относится к выполненной лаборатории; для другого стенда его заменяют. В работе сервера и интерфейса использовался настоящий локальный пароль роли PostgreSQL; он вводился пользователем и сюда не переносился. Файл zabbix.conf.php с подключением веб-интерфейса намеренно не включён.
